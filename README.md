# 🚀 AeroGuard Sim

A high-trust aerospace safety and research simulation platform built for research scholars, professors, and engineering students. 

## Features
- **Interactive 3D Globe:** WebGL-powered Cesium.js interface featuring satellite terrain, realistic rotation, and coordinate point-and-click selection.
- **Realistic Gravity-Turn Trajectories:** Non-vertical parabolic ascent modeling accounting for Max-Q and acoustic stress.
- **NASA PSI-117 Dataset Integration:** Direct traceability to experimental droplet combustion trials ($n$-heptane / $n$-dodecane) with verifiable DOI references.
- **Dual-Mode Architecture:** Tailored for rigorous academic research and engaging student learning labs.
